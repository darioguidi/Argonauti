# Argonauti

Argonauti nasce per essere un piccolo tool da aggiungere al workspace di Claude Code, scritto interamente in C, per la visualizzazione in finestra separata degli agenti in lavoro durante una sessione di sviluppo.

## How use Argonauti in Claude Code
Per utilizzare Argonauti in **Claude Code** è necessario modificare il `setting.json` del workspace nel quale lavoreremo.
